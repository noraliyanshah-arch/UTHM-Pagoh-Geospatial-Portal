# UTHM Pagoh Campus - Geospatial Portal

An interactive Geospatial Visualisation & Research Portal for Universiti Tun Hussein Onn Malaysia (UTHM) Pagoh Campus, featuring GIS mapping, 3D model walkthroughs, and drone tour footage.

## 🚀 Features

- **Interactive GIS Mapping**: Integrated vector and raster spatial datasets covering campus infrastructure and surrounding zones.
- **Multilayer Visualization**: Orthophoto, Block Map, OpenStreetMap, and Point Feature Map layers.
- **3D Walkthrough & Drone Tour**: Immersive spatial representation of the campus and residential colleges.
- **Optimized Performance**: High-efficiency WebP image assets with asynchronous decoding for fast loading.
